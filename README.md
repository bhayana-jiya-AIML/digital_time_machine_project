## ✨ About the Project

**Everly — Digital Time Machine** is a full-stack web application designed to help users preserve personal memories, revisit meaningful experiences, and maintain a digital journal.

With its dreamy purple-and-pink aesthetic, Everly combines memory management and personal journaling in one place. Users can save memories with descriptions, dates, locations, tags, and images, as well as write and revisit personal journal entries.

Everly aims to make preserving life's special moments a simple, personal, and enjoyable experience.

## 🌷 Features

### 🔐 User Authentication
- User registration and login.
- Email format validation.
- Password validation requiring uppercase and lowercase letters, a number, and a special character.
- Password hashing for safer credential storage.

### 🏡 Personalized Dashboard
- A central dashboard for accessing application features.
- Dedicated navigation to memory management and personal journaling.
- A dreamy interface with a soft purple-and-pink visual theme.

### 📸 Memory Management
- Create and save personal memories.
- Add a title and description to each memory.
- Record dates and locations associated with memorable experiences.
- Organize memories using tags.
- Attach images to memories.
- View saved memories through a dedicated interface.

### 📖 Digital Journaling
- Write and save personal journal entries.
- A dedicated lined journal-style writing interface.
- Date and time displayed on the journal page.
- Revisit saved entries through a dedicated journal-viewing section.
- Decorative details and a writing-focused diary aesthetic.

### 🛡️ Security & Data Management
- Password hashing for credential protection.
- AES-GCM encryption for data confidentiality.
- PostgreSQL for persistent data storage.
- Prisma ORM for database access and data management.
